# TEDÜ Yönetmelik Asistanı

TED Üniversitesi'nin yönetmelik ve yönergelerine (staj, burs, yatay geçiş, yan dal, yaz okulu...)
soru sorabildiğiniz, tamamen kendi bilgisayarınızda çalışan bir soru-cevap asistanı.
Microsoft Foundry Local ile yerel bir dil modeli ve RAG yaklaşımı kullanıyor.

Microsoft Yaz Okulu 2026 projesi. Henüz geliştirme aşamasında.
